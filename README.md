# PHP Lab 1

Лабораторна робота № 1: Управління версіями та налаштування конвеєра CI/CD для проекту на PHP.

Цей проект демонструє:
- Управління версіями за допомогою Git та GitHub
- Модульне тестування на PHP за допомогою PHPUnit
- Перевірку стилю коду за допомогою Laravel Pint
- Безперервну інтеграцію за допомогою GitHub Actions
